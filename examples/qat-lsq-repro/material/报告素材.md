# 量化感知训练复现与实验分析（组会素材）

> 供组会汇报使用的原始素材。汇报人：李然；日期：2026-08-27。
> 本文档是素材层：deck.json 从这里蒸馏，实验数字以 `make_figures.py` 内的数据数组为单一真相源。

## 一、背景

实验室在把分类模型往定点推理迁移。训好的浮点网络直接换上量化算子（后训练量化，PTQ），W8A8 几乎无损（78.1%，比 FP16 基线 78.4% 只低 0.3 个百分点）；W4A4 上 top-1 从 78.4% 掉到 61.3%，塌 17.1 个百分点（CIFAR-100 / ResNet-18，3 种子均值）。直接原因是舍入操作几乎处处不可导：训完再量化，没有梯度通路去修正逐层累积的舍入误差。

量化感知训练（QAT）把量化算子插进训练循环：前向用伪量化的权重和激活计算，反向用直通估计（STE）放行梯度。LSQ（Esser et al., 2020）进一步把量化步长 s 变成可训练参数，与网络权重联合优化。本次复现对照 PTQ / QAT-STE / QAT-LSQ 三条路径在 W8A8 / W6A6 / W4A4 下的表现。

## 二、算法

均匀量化与反量化（b 为比特数，s 为步长，z 为零点）：

- Q(x) = clamp(⌊x/s⌉ + z, 0, 2^b − 1)，x̄ = s·(Q(x) − z)
- min–max 校准：s = (x_max − x_min)/(2^b − 1)；权重用逐通道（per-channel）缩放

伪量化与直通估计（对称情形，z = 0）：

- 前向：x̄ = s · clamp(⌊x/s⌉, −2^(b−1), 2^(b−1) − 1)
- 反向：∂x̄/∂x := 1（x 落在量化范围内），范围外取 0

LSQ 步长梯度（对步长 s 求导，舍入残差携带符号）：

- ∂L/∂s = Σ_x (∂L/∂x̄) · (⌊x/s⌉ − x/s)
- 步长用独立学习率 η/√(2^b) 更新；初始化 s0 = r · max|x| / 2^(b−1)，主结果取 r = 2

## 三、复现设置

- 数据：CIFAR-100（50k 训练 / 10k 测试，随机裁剪 + 水平翻转）
- 网络：ResNet-18（PyTorch vision 实现，BN 折叠进卷积）
- 训练：batch 128，100 epoch，学习率余弦退火；每组 3 个随机种子（0/1/2）取均值
- 对比组（其余超参完全一致）：
  1. FP16 基线（不量化）：78.4% ± 0.2
  2. PTQ：训完直接量化，min–max 校准
  3. QAT-STE：伪量化 + 直通估计，步长按滑动 min–max 统计
  4. QAT-LSQ：STE 之上步长可学习
- 补充消融：W4A4 下步长初始化倍率 r ∈ {0.5, 1.0, 2.0, 4.0}（相对 s_max = max|x|/2^(b−1)）

## 四、实验结果

比特宽度扫描（最终测试精度，3 种子均值 ± std）：

| 设置 | W8A8 | W6A6 | W4A4 |
|---|---|---|---|
| PTQ | 78.1 ± 0.1 | 76.5 ± 0.2 | 61.3 ± 0.4 |
| QAT-STE | 78.2 ± 0.2 | 76.9 ± 0.3 | 73.1 ± 0.3 |
| QAT-LSQ | **78.3 ± 0.2** | **77.9 ± 0.2** | **76.2 ± 0.3** |

验证曲线（3 种子均值，14 个采样点，约每 7–8 epoch 一个）与步长消融图由 `make_figures.py` 生成。

观察：

1. W4A4 是分水岭：QAT-LSQ 76.2% 比 PTQ 高 14.9 个百分点，比 QAT-STE 高 3.1 个百分点，距 FP16 基线还差 2.2 个百分点。
2. 验证精度曲线全程 LSQ 高于 STE，收敛后差 3.1 个百分点；PTQ 没有训练阶段，61.3% 是换算子后的水平参考线。
3. 步长初始化消融：r = 0.5 / 1.0 / 2.0 / 4.0 → 73.6 / 75.4 / 76.2 / 74.8（±0.3 到 ±0.4），r = 2.0 最优即主结果设置；偏大一档（4.0）掉 1.4 个百分点。

## 五、结论与后续

- 复现结论：W4A4 的增益主要来自可学习步长（LSQ 对 STE +3.1 个百分点），步长初始化倍率同样关键（r = 2.0 比 0.5 高 2.6 个百分点）；逐通道权重缩放是前提设置。
- 后续：把复现扩展到 ImageNet 子集与 MobileNet 结构；非对称零点对激活量化的影响单独消融。
- 与 Esser et al. (2020) 原文结论的一致性：LSQ 对 STE 的增益方向一致，幅度偏小（原文在 ImageNet 上 W4A4 增益更大），小数据集上属正常。
