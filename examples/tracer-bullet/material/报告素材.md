# AdamW 优化器复现与实验分析（组会素材）

> 供组会汇报使用的原始素材。汇报人：陈晨；日期：2026-08-26。
> 本文档是素材层：deck.json 从这里蒸馏，实验数字以 `make_figures.py` 内的数据数组为单一真相源。

## 一、背景

我们实验室在 CIFAR-10 分类任务上长期使用 Adam 优化器。最近复现一批论文时发现：同样标称 weight_decay=1e-2，Adam 与 AdamW 的最终精度差距能达到 1 个百分点以上。原因是 Adam 把 L2 正则项加进梯度后，正则强度会被自适应学习率 `m̂/√v̂` 缩放——梯度历史大的参数，其正则实际被削弱；梯度历史小的参数，正则反而被放大。等效衰减率随训练动态变化，调参不直观。

AdamW（Loshchilov & Hutter, 2019）把权重衰减从梯度中解耦出来：衰减项不进动量、不进二阶矩，直接按系数 λ 乘到参数本身，正则强度在各参数维度上保持一致。

## 二、算法

Adam 的一阶/二阶矩估计与偏差修正：

- m_t = β₁·m_{t-1} + (1-β₁)·g_t
- v_t = β₂·v_{t-1} + (1-β₂)·g_t²
- m̂_t = m_t / (1-β₁^t)，v̂_t = v_t / (1-β₂^t)

Adam（L2 耦合）更新：g_t 先加 λ·θ，再进 m/v：

- θ_t = θ_{t-1} − η · m̂_t / (√v̂_t + ε)

AdamW（解耦）更新：

- θ_t = θ_{t-1} − η · ( m̂_t / (√v̂_t + ε) + λ·θ_{t-1} )

## 三、复现设置

- 数据：CIFAR-10（50k 训练 / 10k 测试，标准增强：随机裁剪 + 水平翻转）
- 网络：ResNet-18（PyTorch vision 官方实现）
- 训练：batch 128，100 epoch，余弦退火；每组 3 个随机种子（0/1/2）取均值
- 对比组（其余超参完全一致）：
  1. SGD，lr=0.1，momentum=0.9，无权重衰减
  2. Adam + L2，lr=1e-3，weight_decay=1e-2（耦合）
  3. AdamW，lr=1e-3，weight_decay=1e-2（解耦）
- 补充消融（仅记录在素材，不进正稿）：AdamW 的 λ 取 0 / 1e-4 / 1e-2 / 5e-2，最终精度 94.7% / 94.9% / 95.2% / 94.4%——λ=1e-2 最优，5e-2 开始伤精度。

## 四、实验结果

训练损失（3 种子均值，全曲线 14 个采样点，约每 7–8 epoch 一个）与最终测试精度如下；图由 `make_figures.py` 生成。

| 优化器 | 最终测试精度（均值±std） | 末段训练损失 |
|---|---|---|
| SGD (momentum) | 94.6% ± 0.2 | 0.043 |
| Adam + L2 | 93.9% ± 0.2 | 0.061 |
| AdamW | **95.2% ± 0.1** | 0.036 |

观察：

1. AdamW 的损失曲线下降更平稳，Adam+L2 在 60 epoch 后收敛明显偏慢。
2. AdamW 比 Adam+L2 高 1.3 个百分点，且跨种子方差更小（0.1 vs 0.2）。
3. 解耦衰减让 λ 的语义变成"每步直接衰减的比例"，与学习率解耦后可独立调。

## 五、结论与后续

- 复现结论：解耦权重衰减在 ResNet-18/CIFAR-10 上带来稳定增益，与我们此前调参遇到的"weight_decay 不灵敏"现象一致。
- 后续：在更大的任务（ImageNet 子集）和 Transformer 结构上验证；检查不同 λ 与学习率交互。
