# 大纲格式（outline.md）

outline.md 是 CP1 之前的规划文档，用户确认后固化为 deck.json。权威样例：`examples/tracer-bullet/outline.md`。

写作前读 `references/archetypes.md`（页型语义与选择依据）；容量数值以 `templates/blcu-report/manifest.json` 的 `budget` 为真相源；字数计算与 deck.json 同一口径（`references/deck-json-schema.md` 的「字数计算」）。

## 结构（四段，缺一不可）

1. **头部**：汇报人 · 日期 · 输出模式（pptx / web / both）· 素材清单 · 预算来源声明。CP1 答复后回写固化。
2. **页面规划表**：`| # | 页型 | 标题 | 内容要点 | 配图 |`。首页 cover、次页 agenda，中间按内容页型展开；默认**不加** closing 结尾页（用户明确要求致谢页时才加）。内容要点写到「能直接翻成 deck.json 块」的粒度：公式个数、每段主旨、列表条数。
3. **容量预算核对表**：每页 `text_total` 实算值 vs manifest 上限；标题、图注、列表条目各自的上限单独核对；末行给结论（全部在预算内 / 哪页超了怎么改）。
4. **演讲稿要点**：每页讲稿要补什么——页面放不下的细节、报数口径、备问项。

## O1 自查清单（内联，逐项过）

- [ ] 页面序列完整：cover 开场 → agenda → 内容页（默认到内容页为止，不加 closing；用户明确要求致谢时才加）；agenda 条数一屏列得下（上限以 manifest 为准）。
- [ ] 每页页型符合 archetypes.md 的「何时用」；内容形态变化靠页型内变体承载，没有发明新页型。
- [ ] 预算核对表全绿：每页 text_total 及各分项在 manifest 预算内。
- [ ] 配图分配完成：素材图片各归其位；标记「可自绘」的图有把握画准，否则从规划中删除。
- [ ] 内容页构成合规：每个内容页有公式或图承载；纯文字页逐页注明「为何无图无公式」；无「一图一句」的失衡页。
- [ ] 事实可溯源：每个数字、每个结论在素材中有出处（对照步骤 1 的要点清单）。
- [ ] 公式为 LaTeX，写法来自素材或教科书标准式，符号与素材一致。

## CP1 决策清单（独立成题，逐项要用户明确答复）

1. 大纲：逐页过一遍，用户逐项可改。
2. 页数：确认或增删。
3. 输出模式：pptx / web / both（选 web 而 node 缺失 → 呈报 Phase 0 结论请其改选或先装 node）。
4. 封面元数据：汇报人姓名、日期。

改动处理：任何大纲改动 → O1 与 AI 味门对修改后的大纲整体重跑，然后重新确认改动涉及的决策项。
