# AI 味 pattern 清单（内联降级）

no-ai-slop skill 未安装或无法调用时的 AI 味门执行清单（Phase 0 探测决定走哪条路；可调用时优先其 Detect 模式，不走本文）。适用于大纲、页面文字、图注、演讲稿全部成文内容。判定只看原文命中，不猜测写作意图。

使用位置：步骤 2 由执行者内联自查自修；G1/G3 由审查者按 `references/reviewer-contract.md` 使用（finding 按其输出契约与分级包装）。

## 规程

1. 逐段通读全文，对照 pattern 逐个排查（命中特征列的是代表例，同族表达同样命中）。
2. 命中后先对照「合法保留」——落入保留项的不记 finding。
3. 记 finding：`pattern 名 | 原文引证 | 一句修法`。
4. 全部修复后由执行者对**整份文本**重查（不是只查改过的地方），零 finding 过门。

## Patterns

| # | pattern | 命中特征 | 修法 |
|---|---|---|---|
| 1 | 空泛重要性 | 「具有重要意义 / 奠定了基础 / 是关键所在」类断言 | 删断言，换成具体事实或数字 |
| 2 | 无数字的强弱断言 | 「显著提升 / 大幅下降 / 明显优于」，同句或紧邻句无数 | 换素材实数；没有数就删 |
| 3 | 万能开头结尾 | 「随着…的发展 / 综上所述 / 总的来说」 | 直接说事实；结尾停在最后一个具体点 |
| 4 | 排比堆砌 | 三连及以上排比（「更准、更快、更强」）；要点条条同构同长 | 留真实差异，长短错开 |
| 5 | 二元对比 | 「不是 X，而是 Y / 是 Y，而不是 X」，且 X 是稻草人（删 X 不损信息） | 直接说 Y；两侧都是真实内容的技术对比合法 |
| 6 | 假深刻收尾 | 结尾格言、隐喻升华 | 删，停在最具体的结论句 |
| 7 | 解释性元话语 | 「值得注意的是 / 可以看到 / 这一点很重要」 | 删；信息自己站得住 |
| 8 | 无出处转述 | 「研究表明 / 业界普遍认为 / 众所周知」类外部权威，无出处 | 给素材里的出处；没有就删 |
| 9 | 冒号揭秘 | 冒号制造悬念、揭示单点结论（「关键在于：xxx」） | 改普通陈述句；枚举/标签/引用的冒号合法 |
| 10 | 高频 AI 词 | 赋能、抓手、深耕、闭环、深度融合、全方位、有力推动 | 换具体动作 |
| 11 | 破折号堆砌 | 大纲/页面文字/图注的成文文字出现破折号（表格空位记号「—」不计）；演讲稿全文超过 2 处、或一句之内超过 1 处 | 换逗号或句号（演讲稿全文至多 2 处、每句至多 1 处） |

## 合法保留（判定的另一半）

以下不算命中，删了反而伤稿：

- 有数字支撑的「显著 / 明显」——数字在同句或紧邻句（「显著提升 1.3 个百分点」「收敛明显变慢，损失停在 0.061」）。
- 表达真实不确定的「可能 / 大约 / 初步」。
- 演讲稿的口播节奏：页间承接（「先看 / 接下来」）、口语短句、对听众的直呼。
- 指看图、指公式的引导语（「注意 λθ 这一项」「红色框就是解耦衰减的旁路」）。
- 点名了实验设置的「实验表明」（出处即本工作的实验，设置在前文）。
- 素材原文的技术术语与作者原话——忠于素材优先于文风。
